# Cost-Sensitive GA Optimisation of Shewhart **X-bar** Limits  
An industrial case-study in semiconductor manufacturing
--------------------------------------------------------------------------------

This repository accompanies the paper:

> **A. Deelorm**, “Cost-Sensitive Genetic-Algorithm Optimisation of Statistical  
>  Process Control Limits: An Industrial Case Study,” *Submitted to IEEE  
>  Transactions on Semiconductor Manufacturing*, 2025.  

It contains all code, data stubs, and documentation required to **reproduce the
results, figures, and tables** reported in the manuscript.
